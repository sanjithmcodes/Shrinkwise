# Shrinkwise
Shrinkage monitoring tool, made for small businesses.

**Link to project:** [https://shrinkwise.onrender.com/]

## How It's Made:

**Tech used:** React.js, Bootstrap, MongoDB/Mongoose, Node, Express, JavaScript, HTML, CSS, Cloudinary, Passport.js

Shrinkwise is a full-stack web app designed to be the one-stop-tool for finding everything you need to know about shrinkage in your store. Built using the MERN stack, it provides users with a seamless experience to search through losses, and find the necessary data. The frontend is crafted with JavaScript and styled with Bootstrap for a cohesive and responsive design. Passport.js handles the authentication while MongoDB serves as a robust database solution.
